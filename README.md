# Virtualized Cybersecurity Home Lab

Welcome to my fully virtualized cybersecurity lab, designed to develop hands-on experience in Windows system administration, networking, security monitoring, and penetration testing. I hope you enjoy following along in my completion of this project :) 

## Lab Architecture 

This lab consists of 5 virtual machines...

1. Windows Server 2022 --> Active Directory / Domain Controller
2. Windows 11 Client --> Domain-joined client
3. Ubuntu --> Docker services / SIEM log collection
4. Kali Linux --> Security testing
5. pfSense --> Gateway / routing / firewall
